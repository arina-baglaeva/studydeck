# StudyDeck

Веб-приложение для заучивания терминов, определений и английских слов через карточки и мини-игры. Помогает готовиться к зачётам и прокачивать английский для программирования.

## Возможности (план)

- Колоды карточек: термин + определение / слово + перевод
- Импорт карточек из файла (`.txt`, `.csv`) — строки вида `термин - определение`
- Режим «Карточки»: переворачиваешь карточку и отмечаешь «знаю / не знаю»
- Игра «Соедини»: сопоставь термины с определениями на время
- Тест с вариантами ответа
- Режим «Напиши ответ»
- Повторение по системе Лейтнера (интервальное повторение)
- Статистика прогресса

## Стек

- Java 17
- Spring Boot 3 (Web, Data JPA, Validation)
- Thymeleaf
- H2 Database
- Maven

## Запуск

Открыть проект в IntelliJ IDEA и запустить `StudyDeckApplication`, затем перейти на http://localhost:8080

Консоль базы данных: http://localhost:8080/h2-console (JDBC URL: `jdbc:h2:file:./data/studydeck`, пользователь `sa`, без пароля)
